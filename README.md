<h1>PrediMed</h1>
<h3>Machine Learning Based Insurance Cost Prediction System</h3>

<p>
PrediMed is a full-stack machine learning web application that predicts
health insurance costs based on user inputs such as age, BMI, number of children,
smoking status, sex, and region.
</p>
